X402 Cross-Chain Payment API Tester

Payment Flow (X402 Protocol)

Step 1: Create payment intent → receive payment_requirements (X402 standard)

Step 2: Connect wallet and sign authorization using payment_requirements (NO on-chain TX yet)

Step 3: Submit signed proof → backend calls X402 facilitator to EXECUTE the payment

Step 4: Poll status until BASE_SETTLED (source chain settled → funds transferred to Base)

API Endpoints

POST /api/intents - Create intent (email or wallet + amount)

POST /api/intents/{intent_id} - Submit X402 proof

GET /api/intents?intent_id={id} - Get status + receipt

GET /health - Health check
