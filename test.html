X402 Cross-Chain Payment API Tester

API Endpoints

POST /api/intents - Create intent with X402 proof

GET /api/intents?intent_id={id} - Get status + receipt

GET /health - Health check

1. Create Payment Intent

Submit X402 settlement proof and merchant address to create a new payment intent.

2. Check Payment Status

Query the status of a payment intent. Use polling to monitor async processing.

3. Health Check

Check if the API server is running and database is connected.
