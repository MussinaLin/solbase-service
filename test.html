X402 Cross-Chain Payment API Tester

Payment Flow

Step 1: Select payer chain (Solana/Base/BSC) and create payment intent with email or wallet + amount

Step 2: Complete X402 payment on the selected chain (external)

Step 3: Submit X402 proof to the backend

Step 4: Poll status until BASE_SETTLED (funds transferred to Base)

API Endpoints

POST /api/intents - Create intent (email or wallet + amount)

POST /api/intents/{intent_id} - Submit X402 proof

GET /api/intents?intent_id={id} - Get status + receipt

GET /health - Health check
